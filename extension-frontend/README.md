# ReStyld — extension frontend

This folder contains the Chrome extension source (side panel UI, content scripts, and build config).

For a full guide on **how ReStyld works**, including screenshots of design mode, the style inspector, and saving skins, see the [project README](../README.md).

## Quick build

```bash
npm install
npm run build
```

Then load the `build/` folder as an unpacked extension in Chrome (`chrome://extensions` → Developer mode → Load unpacked).
